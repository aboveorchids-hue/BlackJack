# BlackJack 21 點小助手

在 iPad 上用 Safari 開，分享螢幕後自動讀遊戲畫面上的牌，輪到你時用提示音和語音告訴你最優解（補牌／不補牌／加倍）。

網址（開啟 GitHub Pages 後）：https://aboveorchids-hue.github.io/BlackJack/

## 使用方式（iPad）

1. iPadOS 27 以上，用 **Safari** 開上面的網址。
2. 把遊戲和 Safari **並排放在螢幕上**（台前調度／視窗模式）。Safari 不能縮到背景，否則 iPad 會暫停網頁。
3. 按「開始螢幕分享」，在系統視窗選擇分享螢幕。
4. 回到遊戲照常玩。莊家還有一張蓋牌（輪到你）時就會出聲：
   - 補牌：嗶嗶（高音兩聲）＋語音「補牌」
   - 不補牌：嘟—（低音一長聲）＋語音「不補」
   - 加倍：嗶嗶嗶（三聲上揚）＋語音「加倍」
5. 中途翻轉 iPad 沒關係：分享的畫面方向不會跟著轉，小助手會自動試各種方向（約 1 秒）重新鎖定。
6. 讀到的牌加起來＝遊戲顯示的總點數就算確認。萬一確認不了，仍然會照最可能的讀法給建議，並標示「⚠ 讀牌未確認」；點那張牌選正確點數，之後就會自動認得。

也可以在「手動輸入」分頁自己點牌查詢，「策略表」分頁有完整表格。

## 計算規則

- 6 副牌，每局只扣除當局看得到的牌（不跨局記牌）
- 莊家 16 以下補、17 以上停（軟 17 停）
- 莊家明牌 A／10 時先查 BLACKJACK，有就直接結束
- 只有兩張牌時可加倍，加倍只補一張；不能分牌
- BLACKJACK 1 賠 1.5、五龍 1 賠 3、777 1 賠 10、同花 6‧7‧8 1 賠 15
- 加倍後湊成 777／同花 678：原注＋加倍注都照特殊賠率

每一手都用目前看得到的牌，精確計算「補牌／不補牌／加倍」的期望值，選最高的。

照這套規則每手都照建議打，長期期望值約每注 +7%（模擬 20 萬局：+7.35% ±0.56%），主要來自五龍 1 賠 3；前提是遊戲真的照說明隨機發牌。

## 怎麼讀牌

- 在畫面中找出上方莊家牌組、下方玩家牌組（白色牌面、固定的重疊間距），莊家有紅色背面的蓋牌＝輪到你。
- 讀每張牌左上角的點數與花色，跟從遊戲錄影與 iPad 截圖擷取的模板比對（13 種點數都是遊戲實際字形）。
- 再讀遊戲自己顯示的總點數小黑框做交叉驗證；對不上時自動修正單張讀錯的牌，修不了就照最可能的讀法給建議並標示未確認。
- 全部在你的 iPad 上運算，畫面不會上傳到任何地方。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `index.html`, `css/app.css` | 介面 |
| `js/engine.js` | 最優解計算（期望值） |

## 開啟 GitHub Pages

倉庫 Settings → Pages → Build and deployment → Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾 **/(root)** → Save。約一分鐘後上面的網址就能開。
